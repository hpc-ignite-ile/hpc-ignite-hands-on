# คำศัพท์ที่พบบ่อย

ไม่ต้องจำทั้งหมด เปิดหน้านี้เมื่อพบคำที่ไม่คุ้น ชื่อที่ใช้ในคำสั่งต้องพิมพ์ตามตัวอย่าง แม้จะมีคำอธิบายไทยก็ตาม

| คำ | ความหมายแบบง่าย |
|---|---|
| HPC | การใช้คอมพิวเตอร์สมรรถนะสูงเพื่อคำนวณงานที่ใหญ่หรือซับซ้อน |
| CPU / core | หน่วยคำนวณทั่วไป / คอร์คือส่วนที่ช่วยทำงานใน CPU |
| GPU | หน่วยคำนวณที่เหมาะกับงานจำนวนมากพร้อมกัน เช่น ฝึก AI |
| RAM / memory | หน่วยความจำที่ใช้ถือข้อมูลระหว่างโปรแกรมทำงาน ไม่ใช่พื้นที่เก็บไฟล์ |
| node | เครื่องหนึ่งเครื่องในระบบขนาดใหญ่ |
| login node | เครื่องสำหรับเข้าสู่ระบบ เตรียมไฟล์ และส่งงาน ไม่ใช้คำนวณหนัก |
| compute node | เครื่องที่ได้รับจัดสรรให้คำนวณงาน |
| partition | กลุ่มเครื่องที่เลือกเมื่อส่งงาน เช่น กลุ่ม CPU หรือ GPU |
| Slurm | ระบบจัดคิวและแบ่งทรัพยากรให้ผู้ใช้งาน |
| job / job ID | งานที่ส่งให้เครื่องทำ / หมายเลขสำหรับติดตามงานนั้น |
| script | ไฟล์รวมคำสั่งที่ให้เครื่องทำตามลำดับ |
| module | ชุดการตั้งค่าเพื่อเลือกโปรแกรมและรุ่นที่ต้องการ |
| environment | สภาพแวดล้อมของโปรแกรม เช่น Python และแพ็กเกจที่ติดตั้งไว้ด้วยกัน |
| terminal / shell | หน้าต่างพิมพ์คำสั่ง / โปรแกรมที่รับและทำตามคำสั่ง |
| input / output | ข้อมูลเข้า / ผลลัพธ์ |
| log / stdout / stderr | บันทึกการทำงาน / ข้อความผลทั่วไป / ข้อความแจ้งปัญหา |
| workspace | โฟลเดอร์หรือพื้นที่ที่จัดไว้ทำงานหนึ่งเรื่อง |
| baseline | ผลตั้งต้นที่ใช้เปรียบเทียบกับสิ่งที่ปรับใหม่ |
| benchmark | การทดลองที่กำหนดโจทย์ชัด เพื่อเปรียบเทียบความเร็วหรือการใช้ทรัพยากร |
| seed | ค่าเริ่มสุ่ม ใช้ช่วยให้ทดลองซ้ำและเปรียบเทียบได้ |
| rank / thread | กระบวนการหนึ่งในกลุ่ม MPI / สายงานย่อยภายในกระบวนการ |
| batch size | จำนวนข้อมูลที่ส่งให้โมเดลประมวลผลในหนึ่งชุด |
| agent / ABS | ตัวแทนที่มีกฎพฤติกรรม / การจำลองด้วยตัวแทนหลายตัว |
| checksum | ค่าที่ใช้ตรวจว่าเนื้อหาไฟล์เปลี่ยนหรือไม่ ไม่ใช่การรับรองความถูกต้องทางวิทยาศาสตร์ |
| SHr | หน่วยค่าบริการของระบบ ต้องดูจากการคิดค่าบริการ ไม่เท่ากับชั่วโมงคอร์โดยตรง |
