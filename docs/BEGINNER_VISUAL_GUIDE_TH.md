# เริ่มต้นด้วยภาพ: จากเครื่องของคุณสู่ผลทดลอง

เป้าหมายแรกไม่ใช่ใช้เครื่องให้มากที่สุด แต่คือส่งงานเล็กหนึ่งงาน แล้วตอบได้ว่า **รันที่ไหน ใช้อะไร และคำตอบถูกหรือไม่**

ภาพในหน้านี้สร้างด้วย AI เพื่ออธิบายแนวคิด ไม่ใช่ภาพหน้าจอผลการรัน คำอังกฤษในภาพมีคำอธิบายไทยด้านล่าง

## 1. เส้นทางการเรียน

![เชื่อมต่อ เตรียม ส่งงาน รัน ตรวจ และปรับปรุง](images/beginners/tutorial-overview.png)

- **Connect — เชื่อมต่อ:** เข้า LANTA ด้วยบัญชีของคุณ
- **Prepare — เตรียม:** จัดไฟล์ข้อมูลและเลือกโปรแกรม
- **Submit — ส่งงาน:** ขอเครื่องผ่าน Slurm ซึ่งเป็นระบบจัดคิว
- **Run — ทำงาน:** เครื่องคำนวณทำงานเมื่อถึงคิว
- **Check — ตรวจ:** เปิดผลและตรวจคำตอบ
- **Improve — ปรับ:** เปลี่ยนทีละอย่างแล้ววัดอีกครั้ง

เริ่มที่ [ตั้งค่า LANTA](../LANTA_SETUP.md) แล้วทำ [งานแรก](../lanta-experience/01-first-slurm-job.md)

## 2. คำสั่งกับข้อมูลเดินทางคนละเส้น

![เครื่องเข้าสู่ระบบใช้ส่งงาน ส่วนไฟล์เดินทางผ่านเครื่องรับส่งข้อมูล](images/beginners/lanta-job-workflow.png)

**เส้นคำสั่ง:** เครื่องคุณ → SSH → เครื่องเข้าสู่ระบบ → คิว Slurm → เครื่องคำนวณ

**เส้นข้อมูล:** เครื่องคุณ → เครื่องรับส่งข้อมูล → พื้นที่โครงการที่เครื่องคำนวณอ่านได้

เครื่องเข้าสู่ระบบใช้แก้ไฟล์และส่งงาน ไม่ใช้คำนวณหนัก การส่งไฟล์สำเร็จยังไม่ได้แปลว่าเริ่มจำลองแล้ว

สถานะ `PENDING` คือรอ `RUNNING` คือกำลังทำ และ `COMPLETED` คือโปรแกรมจบ จากนั้นยังต้องเปิดผลตรวจว่าถูกต้อง ดูคำสั่งที่ [คู่มือ Bash](BASH_COMMAND_REFERENCE_TH.md)

## 3. วัดก่อนเพิ่มเครื่อง

![เริ่มเล็ก ตรวจคำตอบ วัดเวลา เปรียบเทียบ แล้วปรับทีละอย่าง](images/beginners/performance-learning-loop.png)

CPU คือหน่วยคำนวณทั่วไป ส่วน GPU เหมาะกับงานจำนวนมากที่ทำพร้อมกันได้ โปรแกรมต้องรองรับจึงจะใช้ประโยชน์จากเครื่องที่เพิ่ม

ใช้ข้อมูลเดิม ทดลองซ้ำ แล้วจดเวลา หน่วยความจำ และความถูกต้อง ถ้าผลผิด การรันเร็วขึ้นก็ยังไม่ช่วย เรียนต่อที่ [ใบงานทรัพยากร](RESOURCE_ESTIMATION_WORKBOOK.md)

## 4. เชื่อมคนกับอาคาร

![Mesa จำลองคนและส่งคำขอให้แบบจำลองพลังงานอาคาร](images/beginners/mesa-twinb-learning-map.png)

Mesa ใช้จำลองตัวแทน เช่น คนที่ต้องการปรับอุณหภูมิ ส่วน EnergyPlus คำนวณอุณหภูมิและพลังงานอาคาร ตัวเชื่อมส่งข้อมูลไปกลับตามเวลาเดียวกัน

เริ่มจากจำลองคนอย่างเดียว แล้วใช้อาคารตัวอย่างที่เตรียมไว้ ไม่จำเป็นต้องเริ่มด้วยอาคารจริงขนาดใหญ่ อ่าน [บท Twin-B](../mini-innovation/06-twinb-heatlab-repository.md) และทำตามทีละขั้น

ภาพแสดงแนวคิด ไม่ได้ยืนยันว่าทุกโมเดลหรือทุกวิธีควบคุมถูกต้อง เหมาะสมกับอาคารจริง หรือประหยัดพลังงาน
