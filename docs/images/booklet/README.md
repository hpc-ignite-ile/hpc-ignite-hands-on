# ภาพประกอบจากคู่มือ LANTA Experience

ภาพเหล่านี้ใช้สรุปแนวคิดใน [คู่มือกิจกรรม](../../lanta-hpc-experience-handbook.pdf) เช่น การส่งงาน การแบ่งงาน และการใช้ AI

ที่มา: โครงการ [LANTA HPC Experience Day](https://github.com/hpc-ignite-ile/lanta-hpc-experience-day-north-dashboard) โปรดคงการระบุที่มาเมื่อใช้ประกอบบทเรียน และตรวจสิทธิ์กับเจ้าของก่อนนำไปใช้ในบริบทอื่น

ภาพเป็นภาพอธิบาย ไม่ใช่ผลการรันจริง ตัวเลขและรุ่นโปรแกรมในภาพอาจต่างจากระบบที่ใช้งาน ให้ยึดคำสั่งในบทเรียนและตรวจระบบก่อนรัน
