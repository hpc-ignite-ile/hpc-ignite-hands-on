# 06 จำลองคนกับพลังงานอาคารด้วย Twin-B

อาคารเดียวกันอาจใช้พลังงานต่างกันเมื่อคนใช้งานต่างกัน บทนี้พาเข้าใจการเชื่อมสองโปรแกรม: **Mesa จำลองพฤติกรรมคน** และ **EnergyPlus คำนวณอุณหภูมิและพลังงานอาคาร**

แนวคิดมาจากโครงการ [HPC Ignite Twin-B](https://github.com/wdiazcarballo/hpcignite-twinb) สำหรับเริ่มเรียน ให้ใช้อาคารตัวอย่างสาธารณะก่อนอาคารที่ต้องเก็บข้อมูลจริง

## ก่อนเริ่ม

ทำ [ตัวอย่าง Mesa](03-epidemic-abs-examples.md) และอ่าน [ภาพรวมอาคารจำลอง](04-building-cosimulation-twinb.md) ก่อน คำสั่งอธิบายอยู่ใน [คู่มือ Bash](../docs/BASH_COMMAND_REFERENCE_TH.md)

| ส่วนประกอบ | หน้าที่ |
|---|---|
| ข้อมูลอาคาร IDF | รูปร่าง วัสดุ ห้อง และระบบปรับอากาศ |
| ข้อมูลอากาศ EPW | สภาพอากาศที่ใช้กับการจำลอง |
| EnergyPlus | คำนวณสภาพภายในอาคาร |
| Mesa | สร้างตัวแทนคนและคำขอปรับอุณหภูมิ |
| ตัวเชื่อม | ส่งข้อมูลให้ทั้งสองโปรแกรมตามช่วงเวลาเดียวกัน |

## วงจรหนึ่งช่วงเวลา

1. EnergyPlus คำนวณอุณหภูมิห้อง
2. Mesa อ่านอุณหภูมิและจำลองความต้องการของตัวแทนคน
3. ตัวเชื่อมส่งคำขอปรับอุณหภูมิกลับ
4. EnergyPlus คำนวณช่วงถัดไป แล้วบันทึกผล

ถ้าสองโปรแกรมนับเวลาไม่ตรงกัน ผลอาจดูปกติแต่ตีความผิดได้ จึงต้องตรวจเวลาและคำสั่งที่ส่งจริง

## ลงมือกับอาคารตัวอย่าง

ทำตาม [บทอาคารอ้างอิง](../docs/TWINB_REFERENCE_BENCHMARKS.md) เพื่อเตรียมอาคารห้าโซนและจำลองหนึ่งวันก่อน ชุดนี้แยกจากโครงการ Twin-B ต้นฉบับ จึงไม่ต้องใช้ไฟล์อาคารส่วนตัวหรือแก้โค้ดของผู้อื่น

เมื่อทำงานเล็กได้แล้ว ค่อยเลือกทดลองอย่างใดอย่างหนึ่ง:

- เพิ่มระยะเวลาจากหนึ่งวันเป็นสามวัน
- เปลี่ยนจำนวนตัวแทนคน
- เปรียบเทียบไม่ส่งคำขอควบคุมกับส่งคำขอควบคุม
- เปลี่ยนข้อมูลอากาศ โดยคงอาคารเดิมและบอกข้อจำกัด

## อ่านผลอย่างไร

ดูอุณหภูมิห้อง ค่าอุณหภูมิที่ตั้งให้เครื่องปรับอากาศ และพลังงานไฟฟ้าเทียบตามเวลา โปรแกรมจบไม่ได้แปลว่าประหยัดพลังงานจริง ต้องตรวจว่าไม่มีข้อผิดพลาดร้ายแรง และวิธีควบคุมยังให้สภาพห้องที่ยอมรับได้

ตัวแทนในแบบฝึกหัดเป็นกฎสมมติ ไม่ใช่พฤติกรรมที่สำรวจจากคนจริง จึงไม่ใช้ผลนี้รับรองอาคารหรือออกแบบระบบจริงโดยตรง

## ประมาณและปรับทรัพยากร

เริ่มจาก CPU 1 คอร์ การขอ GPU ไม่ได้ทำให้ EnergyPlus เร็วขึ้นโดยอัตโนมัติ วัดเวลาเริ่มระบบแยกจากช่วงจำลอง ถ้ามีหลายสถานการณ์ที่เป็นอิสระ ใช้ชุดงานย่อยทำแยกกันได้
